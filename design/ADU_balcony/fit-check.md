# ADU + balcony — fit against the lot

Planning check for the drawings in this folder. **Not a survey and not city approval.**
Lot standards are from [`../../property/zoning/`](../../property/zoning/). The site plan
still assumes a 20′ front setback; that number is what the rear yard depends on.

## Where the balcony actually sits

The 10′ × 4′ balcony is on the **west wall of the rear addition**, in the backyard.
It is not in the west side yard.

| Measure | Value |
| --- | ---: |
| East property line to addition | 5.0′ |
| Addition width | 14.0′ |
| Balcony projection west | 4.0′ |
| East line to outer balcony edge | 23.0′ |
| Lot width | 50′ |
| **Clear to the west property line** | **27′** |

RL2 side yards are 5′ at the ground floor and 9′ above. A 27′ clearance is outside both.

## Rear yard

Assumed stack, measured from the front property line:

| Piece | Distance |
| --- | ---: |
| Front setback (assumed, not surveyed) | 20.0′ |
| Existing house depth | 30.5′ |
| Addition main block | 18.0′ |
| **Rear face of the walls** | **68.5′** |
| **Rear yard left (to the 100′ line)** | **31.5′** |
| Spiral (Ø5′, centered just south of the south wall) | +5.0′ |
| **Rear yard left at the spiral** | **26.5′** |

Required rear yard is 20′ (or 10′ if front + rear stay at least 40′). Both 31.5′ and
26.5′ are over 20′ **if the front setback is really 20′**. Each extra foot the house
sits back from the street takes a foot off the rear yard. The rear yard at the spiral
would drop under 20′ only if the front setback were about 26.5′ or more.
